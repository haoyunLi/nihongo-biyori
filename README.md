# 日和手帖

[打开网站](https://haoyunli.github.io/nihongo-biyori/) · [从第一课开始](https://haoyunli.github.io/nihongo-biyori/#lesson/f01/0) · [五十音图](https://haoyunli.github.io/nihongo-biyori/#kana)

为中文零基础学习者设计的 42 节日语小课，每天约 10–15 分钟。从五个元音开始，用中文讲解、日语音频、笔顺动画和情景对话逐步学习。

| 篇章 | 内容 |
| --- | --- |
| 假名与发音 · 10 课 | 元音与拍、平假名各行、浊音与半浊音、拗音、促音、长音、片假名、礼貌句和助词 |
| 旅行日语 · 19 课 | 问路、站台、旅馆入住、问食材、缺货换菜、结账、澄清信息、失物和结课实战 |
| 二次元与交友 · 13 课 | 讨论喜欢的作品、展会购票、选购周边、询问拍摄许可、辨别朋友口语和角色台词 |

五十音图的 11 组基础音（含拨音）和 16 组扩展音都有独立跟练页。点行名可逐字听音、看平假名或片假名笔顺，留白跟读，再用旅行及动漫情景词练习和自测。[从あ行开始](https://haoyunli.github.io/nihongo-biyori/#kana/a)

每节课包含讲解、示范、听辨小测和开口接话（每周第七章为多站小旅行）。「我来接话」可隐藏学习者的日语台词。星标表达可在复习手帖中翻卡，答错的题会进入错题本。进度、收藏和错题保存在当前浏览器的本地存储中。音频随网站提供，支持慢速播放。

## 每日一章

[六周章节路线](https://haoyunli.github.io/nihongo-biyori/#chapters) 每周七章。从假名、菜单、招呼起步，逐步进入点单、听价格、改菜、付款、问站台和结交同好。今天完成一章后可以做复习，也可以提前学；隔天从尚未完成的第一章继续。旧进度沿用原课程编号。

四章把有出处的短台词接进日常场景。每条短引附出典，日语音频为本站教学配音。素材来自《我们这一家》分集介绍、国际交流基金《艾琳的挑战》剧本、东京电视台《孤独的美食家》回顾和《オモウマい店》节目报道。对话与换词练习为原创。

第 28 章保留五个先独立开口再自查的旅行任务，作为行前热身的选做内容。章节和情境任务答错后安排次日复习，假名和相近音沿用原有的即时复听。错题本可按难点筛选，重答后查看上次错选、正确说法与对应知识点，听示范或回录。整句跟读反馈衡量节奏；旅行实战由学习者听后自评。

第五周增加旅馆、问路和便利店，第六周练失物招领、展会和约见。每章的小节列表标出建议分钟数，听示范、跟读短句、遮字回想，再进对话和章末小测。每个教学小节都能断点续学。

平日预计 13–15 分钟，包含开头约两分钟换问法复习、结尾约三分钟章末接话。每周第七章预计 14 分钟：复习 2 分钟、学习与热身 5 分钟、随堂小测 2 分钟、周实战 5 分钟。每周小旅行替代当天普通接话；小测和小旅行均完成才记为学完，旧版的完成记录保留。完整自由对话等可以另外选做。

[每周实战从这里出发](https://haoyunli.github.io/nihongo-biyori/#practice/week-trip/1)：海边寄明信片、同好集市午休、坐电车去京都、展会散场、住旅馆逛街、约在东口看展。六次共 29 轮，只用该周学过的表达，听到新录的问法后自己接话；提示、原句和示范按需展开。每轮独立保存进度，回顾会指出哪一站用了帮助。未接上的表达与普通章末接话共用一个次日复习名额，次日播放不同问法。最后一周结束后仍可从每日章节进入复习。

章内发送后没有接上、借提示才接上或跳过的轮次，按设备的当地日期从次日开始复现。复习播放另一句日语问话，仍用学过的回答回应。普通复习每天最多三句；周实战有四五句卡住时，优先复习这四五句（约三分钟），当天总预算仍不超过十五分钟。积压的旧句保留；隔天没打开也会保留。独立接上即移出，仍需帮助则推迟到下一天再次换问法。进度按轮保存。已经完成的旧章节可以补练章末对话。

## 开口对话

[九种开口场景](https://haoyunli.github.io/nihongo-biyori/#practice/talk)覆盖点餐、车站买票、结交同好、旅馆入住、街头问路、便利店、失物招领、展会购票和约见面。点「开启连续对话」，等对方说完，看到「轮到你」就直接用日语回答。句末停约一秒半，网站会自动收音。听写可信且能接上当前问题时，对方自动追问；识别含糊时可确认、改字或重说同一句。等待开口时持续没有声音会暂停等待重说。可以随时暂停、查看提示或改用日语输入。

播放对方台词时麦克风静音并断开采集；离开场景、切到后台或结束对话会释放麦克风。首次开麦约 55 MB，语音、听写和场景判断在本机完成。逐句确认模式也可使用。结束后能只重练卡住或求助过的问题，下次在同一浏览器仍能找到待练项目。[识别模型和库的来源与许可](./assets/asr/NOTICE.md)

## 柜台接话与章节衔接

第 14 章先练点菜、份数和堂食外带，可直接进入[午餐柜台三轮](https://haoyunli.github.io/nihongo-biyori/#practice/counter/lunch)。第 15 至 17 章依次增加饮料、付款和缺货。每章正文里能听到店员和顾客，章末换一句考。学完第 17 章可以进[六种情境混合接话](https://haoyunli.github.io/nihongo-biyori/#practice/counter/mixed)。每轮每种情境各一题，紧接着重做会听到另外六句。第 28 章的两道口头任务和最后的外带听题另用三句。

这些店员问法和练习为本站编写。餐饮场景的用语可参照[日本文化厅的餐饮会话教学材料](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kyoiku/seikatsusha/h24_nihongo_program_a/pdf/a_17.pdf)。

先听，再自己开口，然后用选项核对表达的意思。可以重听、慢放或看原句。结果会区分独立选对、借助提示和答错后重试。错题保留当时听到的问法、错选的回答和示范，可以回到本章或次日复习。录音跟读比较指定示范的节奏，开放式接话由学习者自行对照。

## 练习室

[今日复习](https://haoyunli.github.io/nihongo-biyori/#practice/daily) 每天从已学假名、已学表达、收藏和错题中选最多 5 张卡。没有学习记录时可从五个元音热身。逐行自测里听错的音和词也会排进复习。看假名或听音输入罗马字、听情景词回想中文、看中文开口说日语，或重答听辨题。答错或忘记的卡在本轮结尾再练，次日再见，独立想起的卡逐步延长复习间隔。

[情景接话](https://haoyunli.github.io/nihongo-biyori/#practice) 提供车站、食堂、购物及动漫交流等六个场景。听完对方的话，再用语块组成自己的回答。食堂和展会售票场景可选择不同的回应目标，完成后可听示范并收藏想再练的句子。

录音窗口可以把原词句中的促音、长音或拨音加入明天的复习。按设备当地日期，卡片到期后先看原词句独立读，再听示范并换一个词练同类节奏。只存词句、目标拍和复习进度。每天仍最多五张卡。

[听回答，去站台](https://haoyunli.github.io/nihongo-biyori/#practice/platform) 用三轮打乱的站员回答练习选站台。听不清时可以开口请求再说一次，听同一个答案，再在图上选择入口。

[动漫台词拆听](https://haoyunli.github.io/nihongo-biyori/#practice/anime) 收录两段本站原创对话。先盲听猜意思，再逐句跟读、点听语块，对照「待っている／待ってる」和「見ている／見てる」。

[相近音听辨](https://haoyunli.github.io/nihongo-biyori/#practice/sounds) 用七组同声线对照练习清浊音、辅音起音、长音、促音、拨音与拗音。每组先看拍数并试听，再做四题盲听。听错的读音会进入今日复习。

在例句、情景对话、假名和情景词旁点麦克风，听示范后录下自己的跟读。网页会将声音与这句预期的读音对齐，按本遍语速找出一处可能偏短或偏长的拍，给出重读方法。点反馈中标出的拍，会先播示范片段，再播本遍录音的对应位置。默认带上前后各两拍，可切换「只听选中拍」、0.75 倍慢放或循环。不能分开的长元音会保留整组。点「只重读这段」会停播并只录屏幕上选中的范围。录完依次播放示范、上一遍和这一遍，支持慢放和循环。第一次的上一遍取自整句，之后取自同一范围上一次的片段录音。可在播放器旁点「回到整句重读」练习完整表达。可从[切手（きって）](https://haoyunli.github.io/nihongo-biyori/#practice/sounds/kitte)开始。每遍最多 15 秒，录音和分析只在本机内存中处理，关闭窗口即清除。

拍长是估计值。连续长元音按整段比较，声音太轻、背景声干扰或边界不稳时会提示再试。单拍只比较整段时长。这项练习假定你读的是屏幕上的词句，关注节奏，不评定音高、口音或发音总分。[声学模型来源与许可](./assets/timing/NOTICE.md)

## 本地预览

在仓库根目录用 Python 3.11 或更高版本运行以下命令，然后打开浏览器访问终端显示的地址。

```sh
python3 -m http.server 8000 --protocol HTTP/1.1
```

本项目使用原生 HTML、CSS 和 JavaScript 模块。GitHub Pages 从 main 分支根目录发布。课程内容和参考教材在 [lessons.js](./lessons.js)，音频生成过程见 [生成脚本](./scripts/generate_audio.py)。
